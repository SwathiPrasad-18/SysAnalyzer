
# AI SysAnalyzer

AI SysAnalyzer is a native desktop system-monitoring application built with Rust.

## Features

- System resource monitoring
- CPU and memory metrics
- Disk usage and I/O monitoring
- Network interface monitoring
- Process listing, filtering, and sorting
- AI-assisted health scores and findings
- Monitoring history and charts
- Logs and findings dashboard
- JSON report export

## Technology Stack

- Rust
- Cargo
- egui / eframe

## Prerequisites

- Rust toolchain
- Cargo

Install Rust from https://rustup.rs/
